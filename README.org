* インストールと設定

Emacs 30.1 以降の =use-package= と =:vc= を使って、GitHub から直接
インストールできます。次を init ファイルに追加してください。

#+begin_src emacs-lisp
(use-package crit-magit
  :vc (:url "https://github.com/askdkc/crit-magit"
       :rev :newest)
  :after magit
  ;; dsh が PATH にない場合は、以下の :custom 設定を有効にして
  ;; DSH checkout の場所を指定する。
  ;; :custom
  ;; (crit-magit-dsh-command
  ;;  "/path/to/deepseek-harness/apps/cli/lib/bin.js")
  :bind ((:map magit-diff-mode-map
             ("C-c r" . crit-magit-review)
             ("C-c w r" . crit-magit-review-whole)
             ("C-c c" . crit-magit-comment)
             ("C-c f" . crit-magit-comment-file)
             ("C-c C-s" . crit-magit-send-session)
             ("C-c s" . crit-magit-review-session)
             ("C-c C-k" . crit-magit-cancel-review)
             ("C-c m" . crit-magit-set-dsh-model))
          (:map magit-status-mode-map
             ("C-c r" . crit-magit-review-whole)
             ("C-c c" . crit-magit-comment)
             ("C-c f" . crit-magit-comment-file)
             ("C-c C-s" . crit-magit-send-session)
             ("C-c s" . crit-magit-review-session)
             ("C-c C-k" . crit-magit-cancel-review)
             ("C-c m" . crit-magit-set-dsh-model)))
#+end_src

これで =crit-magit= がインストールされ、Magit で次のショートカットを
使える設定になります。

- =C-c r= — diff バッファでは現在行／選択範囲／ファイル、status バッファでは全体を DSH へレビュー依頼
- =C-c w r= — diff バッファ全体を DSH へレビュー依頼
- =C-c c= — 現在行または選択範囲へレビューコメントを追加。コメントはセッションに蓄積されるだけで、この時点では DSH へ送らない（セッション ID が未設定なら聞かれ、=RET= でランダム ID を使用）
- =C-c f= — 現在ファイル全体へレビューコメントを追加
- =C-c C-s= — 蓄積した未解決コメントを確定して DSH へまとめて送る
- =C-c s= — 確認なしで現在セッションの未解決コメントを DSH へ送る
- =C-c C-k= — 実行中の DSH 依頼を中止する
- =C-c m= — ACP から DSH モデル一覧を取得して選択

初回起動時に =use-package= の VC サポートが利用できない場合は、まず
次を評価してください。

#+begin_src emacs-lisp
(require 'package)
(package-initialize)
#+end_src

#+begin_src emacs-lisp
(require 'use-package)
#+end_src

* DSH AI レビュー

Magit の diff バッファから、ローカルで稼働する DSH（DeepSeek Harness）
へレビュー依頼を送り、結果を =*crit-magit-review*= バッファに表示できます。
送信前に DSH の ACP プロファイルへ接続して利用可能なモデル一覧を取得し、
選択した provider/model を headless プロファイル（ワンショット実行）へ渡します。

- =M-x crit-magit-review= — 現在行／選択範囲／ファイルのレビュー対象を DSH へ送る（diff／status の展開済み差分上）
- =M-x crit-magit-review-whole= — 全体を DSH へ送る（diff バッファはバッファ全体、status バッファはワーキングツリー全体の diff）
- =M-x crit-magit-set-dsh-model= — DSH ACP からモデル一覧を取得して選択する

** 全体レビューに渡す内容

=crit-magit-review-whole= は、diff バッファでは折り畳み・narrowing の内側も
含めたバッファ全文、status バッファでは staged／unstaged を分けた全差分を
取得します。未追跡ファイルは含みません。現在のセッションが選択され、保存済み
ファイルが存在する場合は、そのコメント全文も一緒に渡します。

送信対象は操作時点で固定します。長い依頼も切り捨てず、UTF-8 の一時ファイルに
保存して DSH にその全文を読むよう指示します。DSH はこのローカル一時ファイルを
読める必要があります。完了・失敗・キャンセル時に一時ファイルを削除します。
全体レビューと対象レビューはレビュー専用で、ソースを変更しないよう指示します。

=crit-magit-cancel-review=（=C-c C-k=）で実行中の依頼を中止できます。
モデル一覧取得は既定で30秒でタイムアウトし、=crit-magit-dsh-discovery-timeout=
で変更できます。

ACP は標準入出力による接続です。crit-magit が依頼ごとに DSH を起動するため、
別ターミナルで =pnpm dsh --profile acp= を常駐させておく必要はありません。
端末で起動できても Emacs の PATH に =dsh= がない場合は、上記の
=crit-magit-dsh-command= に =bin.js= の絶対パスを設定してください。
=bin.js= の起動には Emacs から =node= も実行できる必要があります。

** モデルの選択

=crit-magit-set-dsh-model= またはレビューコマンドを実行すると、DSH ACP の
=session/new= 応答からモデル一覧を取得して選択できます。直前に選択した
provider/model は、既定で =~/.emacs.d/crit-magit-dsh-model.json= に保存され、
次回の補完候補の初期値になります。各レビュー時には一覧を再取得するため、
DSH 側で追加・削除されたモデルも反映されます。

従来の =crit-magit-dsh-models= と =crit-magit-dsh-default-model= は、ACP を
使わないプログラム呼び出しのフォールバックとして残ります。選択した
provider/model は毎回 =--patch= で明示します。Emacs 側の既定ラベルと
DSH headless 側の設定が異なっていても、選択したモデルを渡します。

** 前提条件

- =dsh= コマンドが =PATH= にあること、または =crit-magit-dsh-command= で実行ファイルのパスを指定すること
- DSH に =acp= プロファイルと =headless= プロファイルがあること
- DSH を PATH に置かない場合の指定例（DSH checkout の場所に合わせて変更）

  #+begin_src emacs-lisp
  ;; use-package の :custom 内で、パスを実際の場所に変更する。
  ;; (crit-magit-dsh-command
  ;;    "/PATH/TO/DSH_DIR/apps/cli/lib/bin.js")
  #+end_src
- DSH の headless プロファイルと認証情報が設定済みであること
  （既定は =~/.dsh=、=DSH_HOME= で変更可。Web GUI で設定済みの認証情報が共用されます）

* コメントと再レビュー

** セッション ID

コメントはリポジトリ root の =.critmagit/<session-id>.md= に保存されます。
=session-id= の部分がセッション ID で、レビューコメントのまとまりを識別する
自由な名前です（例: =review-login=）。ファイル名として安全な単一の要素で
あれば何でも構いません。

=crit-magit-session-id= が未設定のまま =C-c c= などのコメント操作をすると、
=minibuffer= で =crit-magit session ID:= と聞かれます。これは追記先の
ファイル名を確定するためです。そのまま =RET= を押すと、タイムスタンプに
基づくランダム ID（例: =session-20260906-143000=）を初期値として新規
セッションを開始します。入力した値はその Emacs セッションの間記憶され、
以後は聞かれません。

聞かれたくない場合は、先に =M-x crit-magit-set-session= で設定するか、init
ファイルで固定値を設定してください。

#+begin_src emacs-lisp
(setq crit-magit-session-id "review-login")
#+end_src

ランダム ID の形式は =crit-magit-default-session-id= で、変更する場合は
=crit-magit-session-id-function= に文字列を返す関数を設定してください。

** コメントの保存と再レビュー

初回作成時に =.gitignore= へ =.critmagit/= を追加します。

- =M-x crit-magit-comment= — diff の現在行または region にコメント（蓄積のみ）
- =M-x crit-magit-comment-file= — diff の現在ファイル全体にコメント（蓄積のみ）
- =M-x crit-magit-send-session= — 蓄積した未解決コメントを確定して DSH へまとめて送る（=C-c C-s=）
- =M-x crit-magit-review-session= — 確認なしで保存済み未解決コメントを DSH に送る
- =M-x crit-magit-open-session= — 現在のセッションファイルを開く
- =M-x crit-magit-copy-session-file= — AI へ渡す指示文を kill-ring にコピー
- =M-x crit-magit-set-session= — 現在のセッション ID を設定・変更する

既定では、コメントを =C-c c= や =C-c f= で保存しても DSH には何も送られず、
セッションファイルに蓄積していくだけです。複数のコメントを書き終えてから
=C-c C-s=（=M-x crit-magit-send-session=）で確定すると、未解決コメントを
まとめて DSH へレビュー依頼できます。コメント保存直後に即送信したい場合は
=(setq crit-magit-review-after-comment t)= を設定してください。

DSH への依頼はすべてレビュー専用です。プロンプトには「ファイルを変更・作成・
削除しない」「commit・push しない」と明示的に指示され、DSH は各コメント ID
ごとに、判定・根拠・別の AI エージェントが適用できる具体的な修正案を書いた
REVIEW コメントを出力します。実際のソース修正は DSH の出力を確認した上で、
自分または別の AI エージェントに適用させてください。

DSH の実行中に追加したコメントも保存され、後で =C-c C-s= から再送できます。
実行中の依頼へ自動追加はしません。

行範囲は同じ hunk 内で指定します。追加側と削除側を混在させた範囲は、
一部だけを黙って送らずエラーにします。両側への指摘はファイルコメントを使ってください。
コメント保存は読み取りから置換までロックします。異常終了で
=.critmagit/<session-id>.md.lock/= が残った場合は、他の書き込みが動いていない
ことを確認してから、その空ディレクトリを削除してください。

** 進行状況の表示

レビュー依頼を送ると、=*crit-magit-progress*= バッファ
（=crit-magit-progress-buffer-name=）が自動的に開き、開始から終了までの
全段階がタイムスタンプ付きで記録されます。

- ACP モデル探索の各フェーズ（サーバー起動、モデル一覧取得、セッション閉鎖）
- 選択したモデルとレビュー要求の送信
- DSH の標準出力（モデルの応答）のストリーミング表示
- プロセスの終了状態と stderr

モードラインにも =crit: DSH review (12s, C-c C-k to cancel)= のように
経過秒と中止操作が表示されます。=C-c C-k=（=M-x crit-magit-cancel-review=）
で実行中の依頼を中止できます。最終的なレビュー結果は
=*crit-magit-review*= バッファに表示されます。

** 検証

通常の単体・プロセステスト（実際のAIには接続しません）:

#+begin_src sh
emacs -Q --batch -L . -l crit-magit-regression-test.el -f ert-run-tests-batch-and-exit
emacs -Q --batch -L . --eval '(setq byte-compile-error-on-warn t)' -f batch-byte-compile crit-magit.el
#+end_src

Magit を load-path に設定して同じテストを実行すると、一時Gitリポジトリ上で
実際の diff／status バッファ、コメント保存、全体レビュー、セッション再送も
検証します。Magit がない場合、この統合テストは skipped として表示されます。
プロセステストの =tests/fake-dsh.py= には Python 3 が必要です。

実DSHとの疎通は =tests/live-dsh.el= で明示的に検証できます。これは実際の
モデルを利用するため、通常のテストには含めません。Magit を load-path に
設定した状態で、=CRIT_MAGIT_LIVE_DSH= にDSH実行ファイルの絶対パスを指定し、
=-L . -l tests/live-dsh.el= を付けてバッチ実行します。
一時リポジトリの約20KBのdiffと日本語コメントを送り、応答内のコメントID・
diff末尾の確認文字列・ゼロ除算の指摘、およびソースが未変更であることを確認します。
